# TM1637 四位数码管驱动 (`Module/tm1637.c/h`)

调参阶段显示一个数字（档位/计数/状态），不占 UART。当前用作开机自检（4 位同显 1→9→0 循环）。

## 硬件接口

| 信号 | 引脚 | 方向 | 说明 |
|------|------|------|------|
| CLK  | PB17 | 主控→数码管 | 时钟, 推挽输出 |
| DIO  | PA12 | 主控→数码管 | 数据, 推挽输出 |
| VCC  | 3.3V/5V | — | 看模块标注 |
| GND  | GND  | — | |

⚠️ **PB17/PA12 与灰度传感器 L1/L2 复用**。灰度未装时给数码管；装灰度前必须停用数码管（`TM1637_TEST=0` + 不调 `TM1637_Init`）。

时序：软件 bit-bang（TM1637 协议，类 I2C，不区分端口，CLK 跨 GPIOB/GPIOA 无碍）。

## API

```c
void TM1637_Init(void);               /* 配 CLK/DIO 推挽输出 (空闲高) */
void TM1637_ShowSame(uint8_t digit);  /* 4 位同显 digit (0-9, 越界截到 9) */
```

> 当前只实现"4 位同显一个数字"（自检用）。要显示 4 位不同数字（如速度 0123），扩展 `TM1637_Show4(d0,d1,d2,d3)` 即可，时序函数 `tm_write` 已就绪。

## 依赖

- 无（纯 GPIO，不依赖 `g_system_ms` / SysTick）
- `ti_msp_dl_config.h`（`DL_GPIO_*`, `IOMUX_PINCM*`）

## 调用约定

- `TM1637_Init()` 在 `main()` 初始化段调一次（`SYSCFG_DL_init()` 之后）
- `TM1637_ShowSame(d)` 按需调（自检时每 500ms 切一个数）
- `tm_delay()` 用 NOP 循环（~几 us @ 80MHz），TM1637 时钟上限 250kHz，余量足

## 排错

| 现象 | 原因 |
|------|------|
| 不亮 | VCC 没接 / CLK·DIO 接反 / `TM1637_Init` 没调 |
| 乱码段 | 时序太快（`tm_delay` 循环调大）/ 段码表错 |
| 亮度低 | `0x88 \| 7` 中的亮度档（0~7）调低 |

## 示例

```c
TM1637_Init();
TM1637_ShowSame(5);    /* 4 位都显示 5 */
```
