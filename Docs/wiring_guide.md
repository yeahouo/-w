# 硬件接线指南(MSPM0G3507 + TB6612 × 2 + MG310P20 × 4)

> 寻迹小车整车接线表。所有改动前**断电**!MG310P20 电机 6 根线,别接错。

## 系统电源架构

```
                           +-----> 7.4V → 两个 TB6612 的 VM(电机电源)
                           |
   7.4V 锂电池(2S)  ──────┤
   (带保护板,容量 ≥ 1000mAh)|
                           +-----> 降压模块 → 3.3V → 主控 VCC / TB6612 VCC / 编码器 VCC
                           |
                           └────-> 共地(GND 必须全部连在一起!)
```

> ⚠️ **电池强烈建议用 2S 锂电(7.4V)带保护板**,放电倍率 ≥ 20C,4 个电机堵转电流加起来可能超过 3A。

> ⚠️ 主控 MSPM0G3507 是 3.3V 逻辑,**绝对不要把 7.4V 直接接 GPIO**!会烧芯片。

## 接线表 1:OpenMV ↔ 主控(单 UART 共享)

| OpenMV 引脚 | 主控引脚 | 说明 |
|------------|---------|------|
| `TX` | `PA11`(UART0 RX) | OpenMV 发,主控收 |
| `GND` | `GND` | **必须共地** |
| (不接 RX) | (PA10 / UART0 TX 留给上位机) | OpenMV 不需要接收 |

> OpenMV 的 RX 不接,主控 TX 直接通过 USB-TTL 给 PC 看日志/遥测。
> 波特率 460800 起步,主人 OpenMV 那边也要匹配(改 MicroPython 代码)。

## 接线表 2:TB6612 驱动板 × 2

每片 TB6612 控制两个电机。两片共 4 路。

### TB6612 公共连接(两片都一样)

| TB6612 引脚 | 接到 | 说明 |
|------------|------|------|
| `VM` | 7.4V 电池正极 | 电机电源(必须直接接电池,别走降压) |
| `VCC` | 3.3V | 逻辑电源 |
| `GND` | 电池 GND + 主控 GND | 共地(电池负极和主控 GND 必须连通) |
| `STBY` | 3.3V(短接到 VCC) | 待机控制,高电平使能 |

### TB6612 #1(控制左前 LF + 左后 LR)

| TB6612 引脚 | 主控引脚(占位,按原理图调整) | 说明 |
|------------|----------------------|------|
| `PWMA` | `PA12`(TIMA0 CCP1) | LF 电机 PWM |
| `AIN1` | `PA16`(GPIO) | LF 方向(0=正转,1=反转) |
| `AIN2` | `GND` | 固定接地,不用 |
| `PWMB` | `PA13`(TIMA0 CCP2) | LR 电机 PWM |
| `BIN1` | `PA17`(GPIO) | LR 方向 |
| `BIN2` | `GND` | 固定接地 |
| `AO1`,`AO2` | LF 电机红/黑线 | LF 电机输出 |
| `BO1`,`BO2` | LR 电机红/黑线 | LR 电机输出 |

### TB6612 #2(控制右前 RF + 右后 RR)

| TB6612 引脚 | 主控引脚 | 说明 |
|------------|---------|------|
| `PWMA` | `PA14`(TIMA0 CCP3) | RF PWM |
| `AIN1` | `PA18` | RF 方向 |
| `AIN2` | `GND` | |
| `PWMB` | `PA15`(TIMA0 CCP4) | RR PWM |
| `BIN1` | `PA19` | RR 方向 |
| `BIN2` | `GND` | |
| `AO1`,`AO2` | RF 电机红/黑线 | RF 输出 |
| `BO1`,`BO2` | RR 电机红/黑线 | RR 输出 |

> 💡 **方向极性**:装车后,如果某轮子正转时实际方向反了,改 `motor_invert[ch]` 数组(在 `BSP/port_impl.c`),不要换线。

## 接线表 3:MG310P20 编码器 × 4

每个 MG310P20 电机 6 根线:

| 线色(常见,以实物为准) | 功能 | 接到 |
|--------------------|------|------|
| 红(粗) | 电机 + | TB6612 的 AO1/BO1 |
| 黑(粗) | 电机 − | TB6612 的 AO2/BO2 |
| 橙 | 编码器 VCC(+3.3V) | 3.3V(4 个编码器并接) |
| 棕/黑(细) | 编码器 GND | GND |
| 绿/黄 | 编码器 A 相 | 主控 EXTI GPIO(见下表) |
| 蓝/白 | 编码器 B 相 | 主控 普通 GPIO |

> ⚠️ **线色不同厂家不同**!主人用万用表测一下:
> - 红黑粗线:接电池电压档,转动电机有电压反应=电机线
> - 其余 4 根细线:橙色和棕色接 3.3V/GND(测电阻),其余两根用示波器看是 A/B 相

### 4 个电机的编码器 A/B 接线

| 电机通道 | A 相主控引脚(EXTI) | B 相主控引脚(GPIO) |
|---------|-----------------|------------------|
| LF(左前) | `PB0` | `PB4` |
| LR(左后) | `PB1` | `PB5` |
| RF(右前) | `PB2` | `PB6` |
| RR(右后) | `PB3` | `PB7` |

> MSPM0 的 GPIO 中断按组(INT_0 ~ INT_7),SysConfig 会自动分。如果 4 个 A 相同组,ISR 里要读所有 4 个引脚判断哪个触发。简化方案:让 SysConfig 把它们分到不同 INT 组。

## 接线表 4:板载外设

| 设备 | 引脚 | 说明 |
|------|------|------|
| LED | `PB22`(板载已接) | 状态指示 |
| USER 按键 | **查原理图!** | 启动按键,接 GND,内部上拉 |
| SWDIO | `PA19`(板载已接) | 调试,不要占用 |
| SWCLK | `PA20`(板载已接) | 调试,不要占用 |
| RESET | 板载 NRST | 复位按键 |

> USER 按键引脚**必须查原理图确认**!常见标号 `KEY_USER` 或 `KEY1`。
> 如果没有 USER 按键,主人在 SysConfig 里随便分配一个 GPIO 接外置按键。

## 调试串口接线(主控 → PC)

主控 UART0 TX(PA10) → USB-TTL → PC:

| 主控引脚 | USB-TTL 模块 | 说明 |
|---------|------------|------|
| `PA10`(UART0 TX) | `RXD` | 主控发,模块收 |
| `GND` | `GND` | 共地 |
| (不接 RX) | `TXD`(留空) | PC 不发命令 |

> 波特率匹配 SysConfig 配置(460800 推荐)。
> 上位机软件:SerialPlot / VOFA+ / MobaXterm / 友善串口助手。

## 上电顺序(防烧)

1. **断电状态**接线,所有线接完才上电
2. 先用万用表测 7.4V 母线:确认正负极对、电压正常
3. 测 3.3V 母线:确认电压 3.25~3.36V
4. 上电后立刻摸主控和 TB6612,过热立刻断电
5. LED 慢闪(IDLE)= 主控正常运行
6. 用上位机串口工具验证日志能输出
7. 用串口发 `0xAA 0x55 0x00 0x00 0x01 0x00 0x00 0x00 0x00 0x0D 0x05` 测 OpenMV 帧解析
   (XOR:0xAA^0x55^0x00^0x00^0x01^0x00^0x00^0x00^0x00^0x0D = 0x05 ≈ 用 Python 算)

## 烧录与调试

- 用 **XDS110**(CCS 自带)或 **JLink**(Keil)通过 SWD 烧录
- SWDIO/SWCLK 在板载已接好,直接插调试器
- 烧录后如果 LED 不闪:复位按键按一下
- Keil 里:`Flash → Download` 烧录;CCS 里:`Run → Resume`

## 常见硬件故障速查

| 现象 | 排查 |
|------|------|
| 上电后冒烟/烫手 | 立刻断电!多半是电源接反或短路 |
| LED 不亮 | 主控没启动,检查电源、烧录、复位 |
| 电机不转 | TB6612 STBY 没接 VCC?VM 没接? |
| 电机只转一个方向 | 方向脚(AIN1)没接或接地了 |
| 电机抖动不转 | PWM 占空比太低(死区内),或 H 桥电流不足 |
| 编码器读数一直 0 | A 相线没接 / 编码器 VCC 没接 / 引脚错 |
| 编码器方向错(倒着数) | A 相 B 相接反,换线 |
| UART 收不到 OpenMV 帧 | TX/RX 接反 / 共地未接 / 波特率不匹配 |
| 主控随机重启 | 电池电压被电机拉低(Brown-out),加大电容或换大电池 |

## 总引脚占用统计

- UART:2(PA10/PA11)
- PWM:4(PA12~PA15,TIMA0 4 通道)
- 方向 GPIO:4(PA16~PA19)
- 编码器 A 相 EXTI:4(PB0~PB3)
- 编码器 B 相 GPIO:4(PB4~PB7)
- LED:1(PB22)
- USER 按键:1(查原理图)
- SWD:2(PA19/PA20)— ⚠️ **与方向脚冲突!**

**冲突警告**:SWD 调试脚 PA19/PA20 与上面方向脚推荐 PA18/PA19 冲突!
调整:方向脚改用 `PA21` / `PA22` / `PA23` / `PA24`(避开 PA19/PA20 调试脚),或用 PORTB 上的引脚。

**最终推荐**:
- 方向脚:`PA21`、`PA22`、`PA23`、`PA24`(避开 SWD)
- USER 按键:`PA25` 或查原理图
- 总占用:23 个 GPIO(MSPM0G3507 LQFP-64 有 40+ 可用,够)
