## 阶段 1:装开发环境(预计 1~2 小时)

### 主人要做什么

1. **装 Keil MDK-ARM**(5.38+)
   - 官网下载 https://www.keil.com/download/
   - 选 MDK-Arm Community / Lite 版(免费)
2. **装 MSPM0 SDK**(必须有,否则编译报错)
   - https://www.ti.com/tool/MSPM0-SDK
   - 默认装到 `C:/ti/`
3. **装 SysConfig**(独立版或 Keil 插件)
   - https://www.ti.com/tool/SYSCONFIG
4. **装 MSPM0G3507 设备支持包**
   - 在 Keil 里 `Pack Installer` 搜 `MSPM0G3507` 安装
5. **装板载调试器驱动**(看天猛星板用什么调试芯片)
   - XDS110:TI 提供
   - JLink:SEGGER 提供
   - CMSIS-DAP:Windows 自带

### Nano 能帮什么

- 解释报错信息
- 帮主人检查 SDK 路径配置

### 完成标志

- [ ] Keil 能新建一个 MSPM0G3507 工程
- [ ] 能打开 SysConfig GUI
- [ ] 能编译立创官方 `01_led` 例程并下载(能看到 LED 闪烁)

### 可能踩的坑

## 阶段 3:接线 + SysConfig 配置(预计半天)

### 主人要做什么

⚠️ **断电操作!所有线接完才上电**

1. **按 `Docs/wiring_guide.md` 接线**
   - 电源(电池→DC-DC→3.3V)
   - OpenMV ↔ 主控 UART(TX/RX/GND)
   - TB6612 × 2 接主控 PWM + 方向脚
   - 4 个编码器 A 相到 EXTI 引脚、B 相到 GPIO
   - LED 板载已接好
   - USER 按键板载已接好
   - USB-TTL 接主控 UART0 TX 给 PC
2. **打开 SysConfig**,按 `Docs/sysconfig_guide.md` 一步步配置 11 步
3. **生成 `ti_msp_dl_config.c/h`**,放到 `BSP/`
4. **改 `BSP/port_impl.c` 顶部的宏**,匹配 SysConfig 实际生成的引脚宏名
5. **补齐编码器 4 路 EXTI ISR**(参考 LF 一路的写法,补 LR/RF/RR)

### Nano 能帮什么

- 帮你检查 SysConfig 报错
- 帮你改 port_impl.c 的引脚宏
- 帮你补编码器 ISR 代码

### 完成标志

- [ ] 全部线接好(用万用表测一遍通断)
- [ ] SysConfig 配完保存
- [ ] Keil 工程能编译通过(没有 undefined symbol)

### 可能踩的坑

- 引脚冲突(SWD 调试脚 PA19/PA20 被占用)→ 换 PA21~PA24
- GPIO 中断同组冲突 → SysConfig 自动分组,看警告
- 编译报错 `xxx_INST undefined` → 宏名对不上,检查 `ti_msp_dl_config.h` 实际生成的名字

## 阶段 4:首次烧录 + 串口日志验证(预计 1 小时)

### 主人要做什么

1. **Keil 编译** `Application/main.c` 等全部源文件(加入工程)
2. **烧录**(Flash → Download)
3. **打开上位机串口工具**(MobaXterm / 友善串口助手 / SerialPlot)

4. **按复位**,看串口输出
5. **板载 LED** 应该慢闪(IDLE 状态)

[10][I][TRACK] init ok, Kp=0.050 Kd=0.200 omega_max=5.0

## 阶段 5:单电机闭环调试(预计 半天~1 天)

### 主人要做什么

⚠️ **先架空车轮**(把车架起来,轮子离地),避免失控飞车!

1. **手转电机轮子**,看上位机波形上 `actual_lf` 是否有变化(编码器 OK)
2. **用串口命令临时给目标速度**(可能要 Nano 写一个简单的串口命令解析)
3. **看 PI 闭环响应**:`target_lf` 和 `actual_lf` 同图
4. **调整 `config.h` 的 `SPEED_PI_KP / KI`**,直到响应快又稳
5. **记录调参过程**到 `Docs/tuning_log.md`
6. **4 个电机分别调**(参数可能略有差异)

### Nano 能帮什么

- **写一个简单的串口命令解析器**(给目标速度、改 Kp/Ki),不用每次烧录
- 帮你分析波形,推荐调参方向

### 完成标志

- [ ] 4 个电机 PI 响应都过关(稳态误差 < 5%,无震荡)
- [ ] 调参记录写到 tuning_log.md

### 可能踩的坑

- 编码器没反应 → 检查 VCC、A 相 EXTI、引脚分配
- 电机只转一个方向 → 方向脚没接或接地
- PI 输出一直打满(报 `PI_DIVERGE`)→ 编码器极性反了,改 `motor_invert[]`

## 阶段 7:循迹调试(预计 1~2 天)

### 主人要做什么

⚠️ **先在简单赛道上测试**:只用白色 KT 板 + 黑色电工胶带(2cm 宽)搭直线 + 圆弧弯

1. **架空调试**:让车在空中跑逻辑,看动作是否合理
2. **落地直线测试**:看 `err` 是否稳定接近 0
3. **落地弯道测试**:调整 `TRACK_PD_KP / KD`,看是否冲出
4. **加速测试**:逐步提高 `SPEED_TARGET_TRACKING`
5. **每次调参都记录**到 tuning_log.md

- 推荐 Kp/Kd 调整方向

### 完成标志

- [ ] 直线不漂,稳态偏差 < 5 像素
- [ ] 圆弧弯不冲出
